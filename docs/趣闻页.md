# 趣闻纸片页

每期末尾的一页轻内容。没有合适探索项时使用，与探索位共用一个位置，不计入最多五条主新闻。可放语言趣闻、小知识、笑话或文化梗。

## 阅读效果

[已确认的效果参考](assets/light-page-reference.png)是比对基准。正文变化会改变折行和纸片高度，不压缩文字去填满或塞进一屏。

- 奶白纸片、银蓝背纸、细框和胶带；右上固定植物插画，不每日生成装饰。
- 纸内只放内容、来源与右下法文类别，不加报头、编号、栏目说明或中文类别标签。
- 正文霞鹜文楷16.5px、行高1.9；标题文楷26px；可选英文词头衬线斜体43px，短释义17px。
- 来源11px、法文类别20px。来源为空时不显示占位说明。
- 最大宽度620px，手机单栏；允许页内纵向滚动，导航在纸片外，使用日报共用「回到目录」按钮，触控尺寸至少44px。
- 纸片保持浅色信笺效果；切换日报主题不反转插画或纸色。无入场动画，不依赖外部资源。

## 写稿时怎么填

仍用现有 Markdown 原稿与标记，只在末条 `story` 加一个 `light` 对象。`category_fr` 必填，`word` 和 `gloss` 可省。正文直接写 `paragraph`，不需要新闻式小节标签；来源沿用原来的 `sources` 区。

```markdown
<!-- story {"id":"paper","number":4,"category":"语言","light":{"category_fr":"Curiosité linguistique","word":"serendipity","gloss":"偶然撞见，恰好有用。"}} -->
## 你没在找的东西，也可能值得找到。
<!-- block paper-p1 paragraph -->
这里放已写好的正文，可以有多个段落。
<!-- sources -->
[来源名称](https://example.org/)
<!-- endstory -->
```

将 `paper` 同样放入 `layout.order` 与 `layout.stories` 的最后，`components` 写 `[]`。`number` 接在主新闻之后；`category` 用于目录，纸片右下只显示 `category_fr`。法文类别可按内容写，例如 `Curiosité linguistique`、`Curiosité`、`Le saviez-vous ?`、`Humour`、`Clin d’œil`。不额外要求编号、词头或释义。

完整可运行示例在 [测试稿](../tests/fixtures/light-page.md)，标注 TEST，不进入正式期次。用现有 `daily.py` 生成即可；共用样式在 `tools/light_page.css`，排版在 `tools/light_page.py`。
