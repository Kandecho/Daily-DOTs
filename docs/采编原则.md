# 新闻采编原则

试行版，结合后续几期的实际阅读效果继续调整。

## 交际目标

向读者讲述正在发生的现实，使其理解值得关注的变化。选题、搜集材料、核实和写作都应围绕这一目标展开。来源追溯、时间区分与事实边界保障报道的准确性，但不能代替报道本身。

当前报道要求决定目标、范围和完成标准；不能把局部正确或部分完成当成整体完成，也不为追求完整、深入或周全而自行扩大任务。

## 交际性：确定这条新闻需要向读者讲清什么

根据事件和读者已有的知识，确定报道需要讲清的事实与必要解释，再据此选择和组织材料。不能以选题理由、核实过程或防止错误的说明，替代读者实际需要了解的事件内容。

新闻事实是信息主体。采编判断应融入事实的选择、顺序和组织，让具体的变化、处境、联系或后果呈现值得关注之处，不给事件强加意义，不把报道写成新闻评论。“为什么值得留下”不要求另写一段重要性判断，也不用于证明事件符合筛选标准。确有特别值得注意之处，可以用一两句短句强调，但不能代替事实讲述或成为每条的固定结尾。

## 信息分配与口吻

先让读者知道发生了什么，再按理解需要安排经过、背景、具体细节和后续进展。重要而不熟悉的事实应适当展开，已清楚的信息不反复概括；篇幅随内容的必要性和充分性决定，不以固定字数或段落数裁切。

使用清楚、平实的报道口吻，以具体事实、动作和有来源的表述推进内容，少用抽象概括、拔高意义或替读者下判断的句子。段落围绕一组相连的信息展开，便于手机阅读，但不为求短而拆散因果、时间顺序和必要联系。

## 必要性：每项内容都要对报道承担具体作用

事实、背景、解释、限定以及结构安排，应帮助读者准确理解新闻，或履行明确的报道要求。采用删除检验：删除后若不会对正确性、必要理解、实际履行或明确要求的结果造成具体损失，就应删除。相关、有用、更完整、更严谨或通常这样写，都不足以单独证明必要性。

来源、日期和限定不因“更严谨”便自动需要展开。例如，“用公司资金补足”与“追回赃款”的区别，会改变读者对损失承担和恢复过程的理解，应当交代；已明确是局部撤离，则不必例行以“这不意味着全面停战”收尾。

删除检验应结合整条报道进行。铺垫、衔接和具体细节可能共同完成理解，不能把必要性执行成逐句压缩，最后只剩事实清单。段落、标题、列表、转折、例子和总结同样需要承担具体作用。

## 充分性：实际完成报道承担的理解任务

证据足以支持已有句子，不代表已有句子足以讲清事件。应发现读者理解这条新闻仍缺少什么：可能是事件经过、必要背景、机制、人的处境，也可能是影响范围或关键未知。缺少材料就定向补查，已有材料未发挥作用就重新组织；不能用“仍待观察”或抽象的重要性判断结束尚未完成的讲述。

写入背景、人物身份、否认或核查结论时，应核对其在全文中的来龙去脉：前文是否已交代为什么需要提及，读者能否理解它与事件的关系。例如，提到某人是谁的儿子，要交代这层关系与所报道事实的关联；说明某件事不是某人所为，应在确有理解需要时交代被回应的说法或疑问及其来源，不能凭空引入一个否定结论，也不能把未经证实的指控写成事实。已有铺垫足够时不重复说明；无关的内容删去，必要但缺失的联系定向查明后补足，不为了交代而增添枝节或补造关联。

充分性不要求每条都交代所有背景、解释深层原因或输出观点。需要讲到哪里，由这件事的理解需要和明确的报道要求决定。无法证实的联系不能补造，关键未知本身需要交代时应如实说明。

## 在采编中使用

先看整条报道是否完成了交际，再看各部分是否必要、是否充分，包括背景、身份与限定是否有必要的前后照应。研究材料中的来源、口径和禁用表述继续约束写作，但不自动成为正文；定稿前按报道需要补足材料并组织全文。

这些原则约束生成过程，不成为正文里的固定章节或逐项自证，也不增加定稿后的全面事实复审或模型审稿。执行顺序见[工作流程](工作流程.md)；原稿标记、来源格式和版面见[排版约定](排版约定.md)。
