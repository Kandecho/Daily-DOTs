# 排版约定

## 阅读成品

- 单期、单文件 HTML；目录为第一页，一条新闻一页。
- 页与页之间横向移动，长正文在当前页内纵向滚动，不默认折叠。
- 手机正文 16.5px、行高 1.9；内容最大宽度 620px。标题使用衬线粗体，正文使用无衬线常规体。
- 目录只显示报头、日期、条数、分类和标题，不混入制作说明、核验记录、摘要或阅读指引。
- “回到目录”固定可见，至少 44px 触控尺寸，保留原生 `href="#p0"` 跳转；底部留安全区，不遮正文。
- 日期依据 `issue_date` 区分过去、当天和未来，数量由程序自动强调，不逐期手工着色。
- 探索位有独立样式，但保留全文、来源和不确定性；打印时按条目分页。
- 字体、样式、脚本和地图内嵌，不依赖 CDN，不加入统计脚本或跟踪像素。

实际样式在 `tools/style.css`、`tools/flip.css`、`tools/flip.html`。改排版应改共用模板并重新测试，不逐期手改成品。

## 原稿格式

以完整示例为结构参考，不复制其新闻并更换日期。

1. 顶部是 `---` 包围的 JSON，不是 YAML。必填 `schema_version=1`、`issue_date=YYYY-MM-DD` 和非空 `title`；若提供 `cutoff`，以本期日期开头并注明时区。
2. `layout.schema_version=1`、`layout.template=claude-flip-v1`。模板名是现有格式的兼容标识，不是外部服务依赖。
3. `layout.order`、`layout.stories[].story_id` 与正文 `<!-- story ... -->` 的 ID 完整对应、顺序一致、不重复。
4. 每条保留标题、`<!-- block ... heading/paragraph -->` 标记、唯一 `<!-- sources -->` 来源区与 `<!-- endstory -->`。
5. 主新闻从 1 连续编号，允许 1–5 条；探索位可无、最多 1 条并放最后。不机械凑满“5+1”。
6. `layout.html`、`layout.emphasis` 等描述字段不覆盖 CSS 或程序规则。视觉参数仍由共用模板控制。

解析器拒绝未知正文、缺失标记和不支持组件，避免静默丢失内容。来源使用完整公开 URL，保留查询参数，但不得带令牌或私人分享参数。事实边界和不确定性写在正文，不只留在不显示的元数据中。

## 地图

`components` 可为空；每条最多一张 `locator_map` 国家定位图：

- `highlights` 非空，`country_id` 使用底图的 `ADM0_A3` 编码。
- `viewport` 为四个经纬度数值，依次为西、南、东、北。
- `caption` 是公开图注，解释高亮含义和局限。
- `points=[]`，不接受点位、传播路径或其他组件。
- 只用 `tools/data/ne_110m_countries.geojson`：Natural Earth 1:110m 简化底图，不用于精确定位；着色不自动表示事件覆盖范围、主权判断或传播方向。

## 变更原则

原稿承载已核实内容，共用模板承载视觉规则，生成程序负责确定性转换与核对。修订先改原稿再生成，不手改 HTML 使其脱离原稿。新增组件或改变手机交互时，需要相应测试和实际阅读检查。
